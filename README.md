# 🚀 CareerAI - Website Konsultasi Karir Berbasis AI

Platform konsultasi karir yang membantu kamu menemukan karir yang paling cocok berdasarkan kemampuan, kebiasaan, dan passion dengan bantuan AI.


Cara Kerja

1.  **Cek Kemampuan:** User menjawab pertanyaan seputar bidang yang dikuasai.
2.  **Jika Tidak Tahu Kemampuan:** AI akan bertanya tentang kebiasaan sehari-hari dan mengobservasi kebiasaan yang berpotensi jadi karir.
3.  **Rekomendasi Karir:** Sistem menampilkan beberapa pilihan karir yang paling cocok.
4.  **Detail Karir:** User melihat apa saja yang perlu disiapkan, skill yang dibutuhkan, dan tantangan di karir tersebut.
    - Jika **tidak sanggup** dengan tantangannya -> Kembali ke halaman pemilihan karir.
    - Jika **sanggup & cocok** -> Lanjut ke halaman motivasi/wejangan.
5.  **Pilihan Passion vs Kemampuan:**
    - Jika user punya passion dan kemampuan yang beda, AI memberi pilihan.
    - **Pilih Passion:** AI berikan roadmap belajar dari nol + link belajar (YouTube, TikTok, Instagram).
    - **Pilih Kemampuan:** AI berikan saran pengembangan skill ke tingkat lanjut.
6.  **Jika Tidak Punya Kebiasaan Produktif:** AI akan menyarankan skill yang mudah dipelajari dan punya peluang karir tinggi.

Fitur Utama

- [x] **AI Career Consultant** - Model AI sebagai konsultan karir personal
- [x] **Skill Assessment** - Segmen pertanyaan untuk menggali kemampuan user
- [x] **Habit to Career** - Mengubah kebiasaan menjadi peluang karir
- [x] **Career Matching** - Rekomendasi karir yang paling relevan
- [x] **Roadmap & Tantangan** - Penjelasan detail persiapan dan tantangan tiap karir
- [x] **Passion vs Skill Logic** - Pilihan karir berdasarkan passion atau kemampuan
- [x] **Learning Resource** - Rekomendasi video belajar dari YouTube / TikTok / IG

Target User
Siswa SMP/SMA, Mahasiswa, Fresh Graduate, dan siapa saja yang masih bingung menentukan arah karir.
